# Auditoría VITI — 2026-08-26

## Hallazgos

### 1. Portal cliente: imports de rutas

`routes/api.php` registra rutas para `ClientPortalController`, `ClientProjectController` y `ClientAppsController`. El encabezado `use App\\Http\\Controllers\\{...}` debe incluir esas clases para que las referencias sean resolubles en el namespace global del archivo.

Estado: **pendiente de corrección en código**. No se modifica `main` durante esta auditoría.

### 2. Integración frontend/backend de notificaciones

El backend expone `/notificaciones/buzon` y `/notificaciones/buzon/leer-todo`; el frontend fue alineado con ese contrato en la rama `feature/command-center`.

Estado: **corregido en frontend de trabajo**.

### 3. Aplicaciones integradas

El frontend diferencia acceso administrativo y de cliente para `ExternalAppPage.vue`, valida URLs HTTPS y restringe el acceso de cliente a aplicaciones disponibles.

Estado: **mejora aplicada en frontend de trabajo**.

## Regla de trabajo

No fusionar ramas de trabajo automáticamente. Cada corrección debe validarse en preview y, cuando sea posible, con pruebas funcionales antes de pasar a `main`.
